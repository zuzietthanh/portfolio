# AGENTS.md

## Project Context

A static portfolio site — React 18, Vite, Tailwind, shadcn/ui. It was
originally generated by an AI app builder and depended on that vendor's hosted
backend for all data. That dependency has been removed: the site now reads
content from local JSON files and builds to a plain static bundle.

There is no backend, no authentication, and no admin UI. Do not add one
without being asked.

## Key Files

- `src/content/*.json` — all site content. This is what the site owner edits.
- `src/lib/content.js` — the only module that reads those JSON files. Every
  page gets its data from here.
- `src/index.css` — design tokens (HSL triplets consumed by
  `tailwind.config.js`) plus the `glass*`, `noise-bg`, and `text-gradient`
  utilities the portfolio components rely on.
- `vite.config.js` — note the `@/*` alias is declared here; `jsconfig.json`
  only informs the editor.
- `public/images/`, `public/documents/` — static assets, referenced by
  absolute path (`/images/foo.svg`).

## Working Notes

- Content is imported at build time, so pages render synchronously. There is
  no fetch and no loading state on the home page by design.
- `src/components/ui/` is stock shadcn/ui. Do not restyle it wholesale —
  override at the usage site instead.
- The site owner is not a developer. `EDITING.md` is written for them; keep it
  in plain language and keep its examples accurate if you change content
  shapes.
- Run `npm run build` before finishing any change.

## History

The vendor export that seeded this repo was corrupted: roughly a dozen files
contained the contents of a *different* file, including `src/index.css` and
`README.md`, whose originals were unrecoverable. Corrupt stock shadcn
components were restored from the shadcn registry; `index.css`, `README.md`,
and `src/lib/PageNotFound.jsx` were rewritten. If you find a file whose
exports do not match its filename, suspect the same corruption.
